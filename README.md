# Optimising shot strategy in golf using evolutionary algorithms

## Overview

This project develops a golf strategy optimisation framework that combines a golf simulator with evolutionary algorithms to discover optimal multi-stroke strategies over a realistic height-mapped golf hole. 

The two optimisation algorithms used are:

- **Genetic Algorithm (GA)** - Single objective optimisation 
- **Non-dominated Sorting Genetic Algorithm 2 (NSGA2)** - Multi-objective optimisation

The simulation models ball flight, roll after landing, terrain elevation, surface types, player handicap, club selection, shot power and direction.

### Features

- Physics-based golf shot simulation
- Height-mapped terrain
- Surface classification
- 14 golf clubs
- Handicap-based shot variability
- Club restrictions
- 3D visualisation using PyVista
- GA and NSGA-II optimisation
- Automatic experiment result saving

## Strategy Representation

Each golf strategy consists of a sequence of strokes. Each stroke is encoded using three decision variables:

```
power - 0-100
direction - 0-360
club index - 0-13
```

The optimisers evolve these variables to discover strategies that minimise the chosen objective(s).

## Config files 

Both optimisation methods use config files located in the configs/.

### Parameters 

```
task - GA or NSGA2
runs - Number of independent algorithm executions
lowerBounds - Minimum values for power, direction and club
upperBounds - Maximum values for power, direction and club
popSize - Population size
generations - Number of generations
objectives - Number of objectives (1 for GA, 2+ for NSGA2)
trace - Enable console output
heightmap - Terrain height image 
surfacemap - Surface classification image 
maxStrokes - Maximum strokes per strategy
handicap - Player handicap
```

## Objectives

### Genetic Algorithm 

Minimises the distance to the hole + 200 times the number of strokes encouraging reaching the hole and using fewer strokes

### Non-dominated Sorting Genetic Algorithm 2

Optimises two objectives at the same time, distance to the hole and number of strokes. This produces a Pareto front of non-dominated strategies. 

## Golf simulation 

Each shot consists of club selection, launch angle calculation, initial ball speed, ball flight, aerodynamic drag, backspin lift, shot curvature, ball landing, rolling and surface interaction. Surface types include fairway, rough, green, bunker and out of bounds.

Rules include:

- Putter is automatically selected on the green.
- Sand wedge is automatically selected in bunkers.
- A penalty is applied for shots that go out of bounds.

## Player model

Higher handicaps introduce greater randomness in shot direction and ball speed. 

## Visualisation 

PyVista is used to display the terrain, surface colours, shot trajectories, club specific shot colours and overall strategy visualisations

## Results

Each optimisation run creates a new directory:

```
results/
    GA/
        test-1/
        test-2/
        ...
    NSGA2/
        test-1/
```

Each experiment produces:

- **best-strategy.png** – Visualisation of the best strategy.
- **(algorithm)-config-params.txt** – Configuration used.
- **(algorithm)-convergence.csv** – Convergence history across runs.
- **(algorithm)-results.csv** – Run statistics including distance to hole, strokes, runtime and fitness.

best-strategy.png shows the best strategy found across all runs of the algorithm.

(algorithm)-config-params.txt contains the configuration parameters used for the experiment. 

(algorithm)-convergence.csv file shows the convergence behaviour across all runs included in the experiment.

(algorithm)-results.csv file contains run number, distance to hole, stokes, if it reached the hole, fitness depending on algorithm and runtime.
